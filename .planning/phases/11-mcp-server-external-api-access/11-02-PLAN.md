<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser (cookie session) -> /api-tokens | Authenticated landlord creates/lists/revokes their own tokens; body is untrusted (zod validated) |
| API process -> MariaDB | Only hashes land in api_tokens; a DB dump must not yield usable tokens |
| Environment -> API process | API_TOKEN_PEPPER is a server-only secret; absence must fail closed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Information Disclosure | api_tokens.token_hash / mint response | mitigate | Store sha256(pepper + raw) only (Task 2); plaintext returned once in the 201 body and never selected or logged again (Task 3); 256-bit random tokens make offline brute force infeasible |
| T-11-01b | Information Disclosure | Stolen DB dump without pepper | mitigate | Pepper lives only in process env (API_TOKEN_PEPPER), fail-closed accessor (Task 2) |
| T-11-08 | Elevation of Privilege | PAT used to mint or revoke tokens | mitigate | Router-level 403 when tokenId is set (Task 3) |
| T-11-10 | Information Disclosure | listTokens leaking hashes | mitigate | Service never selects tokenHash; route re-projects to ApiTokenPublic (Tasks 2, 3) |
| T-11-11 | Tampering | Cross-user revoke (IDOR) | mitigate | revokeToken where(and(eq(id), eq(userId))) (Task 2); route test asserts scoping |
| T-11-12 | Information Disclosure | Timing side channel on hash compare | mitigate | Indexed exact lookup plus timingSafeEqual on the final compare (Task 2) |
| T-11-SC | Tampering | npm installs | accept | No new packages; node:crypto, drizzle-orm, hono, zod already present |
</threat_model>
