<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Claude client -> MCP process (stdio) | Model-chosen tool arguments are untrusted; zod raw shapes validate them before any HTTP call |
| MCP process -> Rentular API (HTTPS) | The only privilege the process holds is the PAT; the API enforces scope, role and property access |
| User's machine -> env config | The PAT lives in the client config file on the user's machine |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-03 | Elevation of Privilege | Write tools called by a viewer or read token | mitigate | Tools never self-authorize; the API returns 403 (Plans 03, 04) and the tool surfaces isError with a refusal message (Task 2) |
| T-11-05 | Repudiation | Tool calls not attributable | mitigate | Every request carries X-Rentular-Tool so api_tool_calls names the tool (Task 1, Task 2) |
| T-11-09 | Information Disclosure | PAT in logs or stdout | mitigate | Client never logs the token; all logging to stderr; README warns not to commit the PAT (Task 1, Task 3) |
| T-11-17 | Tampering | Malformed tool args (prompt injection into arguments) | mitigate | zod raw shapes with regex for months/dates, positive numbers, enums (Task 2); API re-validates with zValidator |
