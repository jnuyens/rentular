<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Any HTTP client -> authMiddleware | Untrusted Authorization header; must resolve or reject, never fall through |
| Bearer client -> state-changing routes | No browser Origin; CSRF exemption must be limited to rtl_ Bearer requests |
| API -> Redis | Rate-limit counters; Redis outage must not take the API down |
| API -> api_tool_calls | Audit rows must not contain secrets |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-02 | Spoofing | authMiddleware Bearer branch | mitigate | findActiveTokenByHash enforces revokedAt IS NULL and expiry on every request; any failure sets userId null and returns before the cookie path (Task 1) |
| T-11-03 | Elevation of Privilege | PAT reaching route handlers | mitigate | PAT supplies only userId; getAccessiblePropertyIds / getUserPropertyRole run unchanged; requireWriteScope blocks read tokens on writes (Task 1, Task 3) |
| T-11-06 | Tampering | CSRF wrapper | mitigate | shouldSkipCsrf exempts only "Bearer rtl_" and the existing webhook paths; cookie requests keep the Origin check (Task 2, Task 3) |
| T-11-05 | Repudiation | Bearer API calls | mitigate | bearerAuditLog records tool/userId/tokenId/status/httpStatus per Bearer request, including denied ones (Task 2, Task 3) |
| T-11-07 | Denial of Service | Token abuse / tool loops | mitigate | bearerRateLimit INCR+EXPIRE per token per minute, 429 with Retry-After (Task 2) |
| T-11-07b | Denial of Service | Redis unavailable | accept | Rate limit fails open with an error log; API availability preferred for per-user tokens; audit still records |
| T-11-09 | Information Disclosure | Logs and audit rows | mitigate | No token or hash ever logged; redactAuditArgs scrubs token/secret/password/iban/authorization keys (Task 1, Task 2) |
| T-11-14 | Spoofing | Non-rtl Bearer header (foreign token) | mitigate | Treated as a PAT attempt and rejected without cookie fall-through; no CSRF skip for it (Task 1, Task 2) |
| T-11-SC | Tampering | npm installs | accept | No new packages (ioredis, hono already present) |
</threat_model>
