<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser/PAT -> /billing | Authenticated callers; PATs must not start purchases |
| Stripe -> /stripe/webhook | Unauthenticated network input; only the signature makes it trustworthy |
| success_url -> web | Attacker-controllable query string; must never grant a plan |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-13 | Spoofing | POST /stripe/webhook | mitigate | stripe.webhooks.constructEvent on the raw body with STRIPE_WEBHOOK_SECRET; 400 otherwise |
| T-12-14 | Tampering (replay) | webhook processing | mitigate | webhook_events.event_id unique; duplicates acknowledged with 200 and not reprocessed; state re-fetched from Stripe on every event |
| T-12-15 | Elevation | ?checkout=success | mitigate | Web only polls GET /billing/status; plan state is written by the webhook alone |
| T-12-16 | Elevation | leaked PAT | mitigate | requireBrowserSession (403 when tokenId set) on POST /billing/* |
| T-12-17 | Tampering | checkout body | mitigate | zod enum intent only; price ids and customer chosen server-side |
| T-12-18 | Information disclosure | error responses | mitigate | Generic 502 "Billing provider error"; Stripe messages only in server logs |
| T-12-SC | Tampering | npm installs | accept | No new packages |
</threat_model>
