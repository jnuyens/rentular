## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | hsl(0 0% 100%) / `--background` | Page background, card backgrounds |
| Secondary (30%) | hsl(210 40% 96%) / `--secondary` | Sidebar, nav, muted card sections, table headers |
| Accent (10%) | hsl(207 90% 46%) / `--primary` | Primary CTA buttons, active tab indicator, mandate "active" badge |
| Destructive | hsl(0 84% 60%) / `--destructive` | Cancel mandate button, failed/expired badge, destructive confirmations |

Accent reserved for:
- "Setup Mandate" primary button
- "Save" primary button on GoCardless settings
- Active mandate status badge background
- Active sidebar nav item highlight
- Primary CTA in empty states

### Mandate Status Badge Colors

| Status | Background | Text | Tailwind Classes |
|--------|-----------|------|-----------------|
| Active | hsl(142 71% 45%) / green-500 | white | `bg-green-500 text-white` |
| Pending | hsl(38 92% 50%) / amber-500 | white | `bg-amber-500 text-white` |
| Cancelled | hsl(0 0% 45%) / gray-500 | white | `bg-gray-500 text-white` |
| Failed | hsl(0 84% 60%) / destructive | white | `bg-destructive text-destructive-foreground` |
| Expired | hsl(0 84% 60%) / destructive | white | `bg-destructive text-destructive-foreground` |

Source: D-14 specifies "color-coded mandate status badge (green=active, yellow=pending, red=failed/cancelled/expired)". Cancelled uses gray to distinguish from hard failures. Failed and expired share destructive red.

## Page & Layout Specifications

### 1. Settings Page: GoCardless Tab (D-01 through D-04)

**Replaces:** "General" tab (currently "Coming Soon" placeholder)
**Tab label:** "GoCardless" (rename from "General")
**Tab icon:** `Landmark` (Lucide) -- already imported in settings page

**Layout:** Single Card with 3 sections separated by `<Separator />`:

**Section 1: Connection Status (D-02)**
- Row layout: label left, value right
- "Status" row: green circle indicator (`bg-green-500 rounded-full w-2.5 h-2.5 inline-block`) + "Connected" text when token configured; red circle + "Not Configured" when missing
- "Environment" row: Badge showing "Sandbox" or "Live"
- "API Token" row: masked display `gc_live_****xxxx` (last 4 chars)
- Footer note: muted text "GoCardless is configured via environment variables. Contact your administrator to change."

**Section 2: Creditor Info (D-04)**
- Row layout: label left, value right
- "Creditor ID" row: monospace text
- "Scheme" row: "SEPA Core" text
- Loading state: 2 Skeleton rows (h-4 w-48) while fetching from GoCardless API
- Error state: inline alert "Unable to fetch creditor information. Check your GoCardless configuration."

**Section 3: Default Payment Method (D-03)**
- Label: "Default Payment Method for New Leases"
- Select dropdown with 3 options: "GoCardless (SEPA Direct Debit)", "Bank Transfer", "Manual"
- Save button below, right-aligned
- Toast on save: "Default payment method updated"

### 2. Mandates Page (D-09 through D-12)

**Route:** `/dashboard/mandates`
**Sidebar position:** Between "Payments" and "Communications" (nav key: `mandates`, icon: `FileSignature` from Lucide)

**Page header:**
- Title: "Mandates" (text-2xl font-bold)
- Subtitle: "Manage SEPA direct debit mandates for your tenants" (text-muted-foreground text-sm)
- "New Mandate" button (primary, top-right) -- opens MandateSetupModal

**Filter bar:** (flex row, gap-sm, items-center)
- Status filter: Select dropdown with options: All, Active, Pending, Cancelled, Failed, Expired
- Search: Input with placeholder "Search tenant or property..." (w-64 on desktop, full-width on mobile)

**Desktop table (D-10) -- hidden on mobile (`hidden md:block`):**

| Column | Width | Content |
|--------|-------|---------|
| Tenant | auto | Tenant full name |
| Property | auto | Property address (truncated) |
| Lease | auto | Lease reference or period |
| Status | 100px | MandateStatusBadge component |
| Created | 100px | Date formatted (DD/MM/YYYY) |
| Next Charge | 100px | Date or "--" if no scheduled charge |
| Actions | 80px | DropdownMenu: "View Details", "Cancel Mandate" |

**Mobile card layout (`md:hidden`):**
- Card per mandate
- Top row: tenant name (font-medium) + MandateStatusBadge (right-aligned)
- Middle row: property address (text-muted-foreground text-sm)
- Bottom row: "Created: {date}" + actions dropdown button (right-aligned)

**Empty state:** Centered card with `FileSignature` icon (h-12 w-12 text-muted-foreground), heading and body text, primary CTA button

**Per-row actions (D-12):**
- "View Details": navigates to mandate detail (or expands inline -- use Dialog for MVP)
- "Cancel Mandate": opens CancelMandateDialog with cascade warning

### 3. MandateSetupModal (D-05 through D-07)

**Trigger points:** Lease detail, tenant profile, mandates page "New Mandate" button, onboarding wizard step 4

**Dialog size:** `max-w-lg` (32rem / 512px)

**Content layout:**

Step 1 -- Select Tenant (if not pre-filled):
- Label: "Select Tenant"
- Select dropdown listing tenants without active mandates
- Pre-filled and disabled when triggered from lease detail or tenant profile

Step 2 -- Confirm & Send:
- Summary card showing: tenant name, tenant email, property address, lease reference
- Info callout (muted background, border-l-4 with primary color): "An authorization email will be sent to the tenant at {email}. They will complete the mandate setup on GoCardless's secure page."
- Primary CTA button: "Send Authorization Email"
- Cancel button: secondary/outline variant

**Loading state after submit:**
- Button shows spinner + "Sending..." (disabled)
- On success: Dialog body replaces with success message: check-circle icon (green) + "Authorization email sent to {email}. The mandate will become active once the tenant completes authorization."
- "Done" button closes dialog

**Error state:**
- Inline alert (destructive variant): "Failed to create mandate setup. {error message}. Please try again or check your GoCardless configuration."
- Button re-enables for retry

### 4. CancelMandateDialog (D-12, D-15)

**Component:** AlertDialog (shadcn)
**Trigger:** "Cancel Mandate" action from mandates table row or lease detail

**Content:**
- Title: "Cancel Mandate"
- Description: "Are you sure you want to cancel this SEPA mandate for {tenant name}? This will also cancel all pending payments associated with this mandate. This action cannot be undone."
- Cancel button: "Keep Mandate" (outline)
- Confirm button: "Cancel Mandate" (destructive variant)

**After confirmation:**
- Toast: "Mandate cancelled. {N} pending payments were also cancelled."
- Table row updates to show cancelled status
- If on lease detail: mandate badge updates to cancelled

### 5. Payment Method on Lease Form (D-13)

**Location:** Lease creation and edit forms
**Component:** RadioGroup with 3 options

**Layout:** Vertical stack with 16px gap between options

| Option | Label | Sub-content when selected |
|--------|-------|--------------------------|
| `gocardless` | "GoCardless (SEPA Direct Debit)" | Shows MandateStatusBadge if mandate exists, or "Setup Mandate" button if no mandate |
| `bank_transfer` | "Bank Transfer" | Shows BankAccountSelect dropdown for selecting bank account + structured communication display |
| `manual` | "Manual" | No additional content |

**RadioGroup item layout:** Each item is a bordered card-like container (`border rounded-md p-4`). Selected item has `border-primary ring-2 ring-primary/20`. Radio circle left, label right of radio, sub-content indented below label.

### 6. Lease Detail Additions (D-14 through D-16)

**Mandate info section:** New card or card section on lease detail page

- Row: "Payment Method" -- text showing selected method
- Row: "Mandate Status" -- MandateStatusBadge (only shown when payment method is GoCardless)
- Row: "Last Payment" -- status badge + date (only shown when GoCardless payments exist)
- Quick actions: "Setup Mandate" button (when no active mandate + method is GoCardless) or "Cancel Mandate" button (when active mandate exists)

### 7. Tenant Profile Mandate Display (Claude's Discretion)

**Location:** Tenant detail/profile page
**Layout:** Additional info row or small card

- Row: "SEPA Mandate" -- MandateStatusBadge if mandate exists, or "No mandate" muted text
- If mandate exists: mandate ID (monospace, truncated), created date
- Action: "Setup Mandate" button if no active mandate
