<!-- API endpoints (from Plan 02) the frontend calls -->

POST /api/v1/import/
  Body: { email: string, password: string }
  Response: { data: { sessionId: string, status: "pending" } }

GET /api/v1/import/status/:sessionId
  Response: { data: { id, status, progress, discoveredData, selectedProperties, importedCounts, errorMessage, createdAt, updatedAt } }
  Note: progress is { step: string, message: string, current: number, total: number }
  Note: discoveredData is array of { name, address, type, tenants[], leases[], payments[] }
  Note: importedCounts is { properties: N, tenants: N, leases: N, payments: N, skipped: N }

POST /api/v1/import/start-discovery/:sessionId
  Response: { data: { sessionId, status: "discovering", jobId } }

POST /api/v1/import/start-import/:sessionId
  Body: { selectedProperties: number[] }
  Response: { data: { sessionId, status: "importing", jobId } }

DELETE /api/v1/import/credentials/:sessionId
  Response: { data: { sessionId, credentialsDeleted: true } }

GET /api/v1/import/latest
  Response: { data: session | null }

**API fetch helper:**
```typescript
async function apiFetch(path: string, options?: RequestInit) {
  const res = await fetch(`${API_URL}/api/v1/import${path}`, {
    credentials: "include",
    ...options,
    headers: { "Content-Type": "application/json", ...options?.headers },
  });
  return res.json();
}
```

**Polling query for session status:**
```typescript
const { data: statusData } = useQuery({
  queryKey: ["import-status", sessionId],
  queryFn: () => apiFetch(`/status/${sessionId}`),
  enabled: !!sessionId,
  refetchInterval: (query) => {
    const status = query.state.data?.data?.status;
    if (status === "discovering" || status === "importing") return 2000;
    return false;
  },
});
const session = statusData?.data;
```

- `startImport`: POST /start-import/:sessionId with selectedProperties array
- `deleteCredentials`: DELETE /credentials/:sessionId
- `startNew`: resets local state (sessionId = null, selectedIndices clear)
