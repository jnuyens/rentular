<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet (GitHub) → webhook receiver | Untrusted POST that triggers arbitrary code execution (deploy) |
| Internet → nginx | TLS termination; only ingress to the app tier |
| deploy.sh → shell | Runs build + docker + bootstrap with box privileges |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-05-01 | Elevation of Privilege | Unauthenticated deploy webhook → RCE | mitigate | HMAC-SHA256 constant-time verify of X-Hub-Signature-256 + deploy-branch allowlist before exec; unit-tested |
| T-10-05-02 | Tampering | Deploy of unverified/forged ref | mitigate | Receiver ignores non-main refs (200 no-op); only verified main push runs deploy.sh |
| T-10-05-03 | Information Disclosure | Deploy logs leaking /opt/rentular/.env | mitigate | deploy.sh never cat/echo the secrets file; receiver never logs secret/raw body |
| T-10-05-04 | Spoofing | Insecure cookies / wrong callback behind proxy | mitigate | nginx forwards X-Forwarded-Proto https + Host; pairs with AUTH_URL + trustHost |
| T-10-05-05 | Denial of Service | Broken release flipped live | mitigate | pnpm build gate before symlink flip; failure leaves `current` unchanged; rollback documented |
| T-10-05-SC | Tampering | node --test / no new deps | accept | Receiver uses Node built-in crypto/http only; no new npm packages — no legitimacy gate needed |
</threat_model>
