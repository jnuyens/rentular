<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo working tree → Docker build context | .env and secrets must not be copied into image layers |
| build ARG → browser bundle | NEXT_PUBLIC_API_URL is baked and publicly visible (non-secret by design) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-03-01 | Information Disclosure | Secrets baked into image layers | mitigate | .dockerignore excludes .env/.env.*/.git/.planning; only NEXT_PUBLIC_* (non-secret) passed as build ARG |
| T-10-03-02 | Tampering | "deploys green, app broken" via runtime-only API URL | mitigate | NEXT_PUBLIC_API_URL set as ENV before next build (baked); Plan 06 smoke verifies no localhost:4000 in served HTML |
| T-10-03-03 | Denial of Service | Wrong standalone path → container crash-loop | mitigate | CMD uses verified deep path apps/web/server.js; docker run smoke in Wave-2 completion check |
| T-10-03-SC | Tampering | base image / turbo pin | accept | node:20-slim official image + turbo@2.3.0 pinned (already in repo) — no new npm installs |
</threat_model>
