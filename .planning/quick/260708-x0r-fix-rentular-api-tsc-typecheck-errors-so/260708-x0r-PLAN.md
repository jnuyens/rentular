# Quick Task 260708-x0r: Fix @rentular/api tsc typecheck errors

## Problem

`pnpm lint` (which runs `tsc --noEmit` in apps/api) is RED with **59 errors** across 14 files.
These are long-standing, pre-existing type errors that build (tsup) and tests (vitest) tolerate
because they are type-only, but they block a clean `pnpm lint` gate.

## Root causes (grouped)

**Group A — Date/string mismatch (~45 errors).** Drizzle `date("...")` columns default to
`mode: "date"` → typed as `Date`. But mysql2 returns DATE columns as `"YYYY-MM-DD"` strings and
the entire codebase reads/writes them as strings. The schema type disagrees with runtime + code.
**Decision (user-approved):** change the 17 `date()` columns to `{ mode: "string" }` so the type
matches runtime reality. Type-only change; emitted SQL and stored data are unchanged.

**Group B — `getDb().query` typed `{}` (4 errors: TS2339).** `connection.ts` annotates
`let _db: ReturnType<typeof drizzleMysql>`, dropping the `<typeof schema>` generic and erasing the
relational `.query.*` types. One-line generic fix resolves all 4.

**Group C — missing module decls (2 errors).** `nordigen-node` (TS7016, no types) and
`playwright-core` (TS2307, transitive-only, imported as a type in smovinScraper). Add ambient
`declare module` shims for nordigen-node; retarget the playwright-core type import to `playwright`
(a direct dep that re-exports `BrowserContext`).

**Group D — misc (~8 errors).** BullMQ v5 removed `timeout` from job options (TS2353, 2 files) —
remove it; implicit-any params + unknown[]→string[] + null guard in importDiscoveryWorker;
null-safety cast in bootstrap.test.ts.

## Tasks

1. **Schema + connection type fixes** — flip 17 `date()` columns to `{ mode: "string" }`; fix
   `connection.ts` `_db` generic. Add ambient module shims (nordigen-node) + retarget
   playwright-core import.
2. **Fix fallout + call-site errors** — after schema flip, re-run tsc; fix any Date-writes to now
   string-typed columns (transactionMatcher `new Date()`, its test expectation), BullMQ `timeout`,
   importDiscoveryWorker any/unknown/null, bootstrap.test.ts. Iterate to zero.
3. **Verify** — `pnpm --filter=@rentular/api lint` clean; api test green; web build succeeds.

## Non-goals
- No logic/behavior changes. No new features. No DB migration (types only).
