<objective>
Two messaging changes in the Rentular API.

1. Email every tenant linked to a lease, not only the primary one. One shared helper resolves the recipients (primary stays the "to" address, the name and the language source; all other linked tenants with an email become cc), and every tenant-facing email sender uses it. SMS and WhatsApp stay primary-only. The communications log keeps one row per email and records the cc list in its existing `metadata` json column (no schema change).

2. Rebuild the default indexation letter in NL/FR/DE/EN after the landlord's reference letter (`.planning/quick/261021-nj9-email-all-lease-tenants-and-new-indexati/reference-letter-nl.txt`), with Belgian number and date formatting, the Royal Decree health-index sentence, the Flemish EPC correction paragraph with its computation, round-down and standing-order sentences, and a full signature block. Wire the new parameters through the indexation preview and apply routes.

Purpose: lease 167863a8 (Tervuursestraat) has primary tenant Akpinar and a second linked tenant (R. Vandebroek, lawyer); today only Akpinar receives anything. The current default indexation email is a short ASCII-ized note that does not match the letter the landlord actually sends.
