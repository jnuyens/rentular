API contract from Plan 03:

- GET /api/v1/bank-connections → { data: [{ id, provider, institutionId, institutionName, iban, status, consentExpiresAt, lastSyncAt, errorMessage, country, createdAt, updatedAt }] }
- GET /api/v1/bank-connections/:id → { data: { ...same shape... } }
- GET /api/v1/bank-connections/institutions?country=BE → { data: [{ id, name, bic, country, logoUrl? }] }
- POST /api/v1/bank-connections { institutionId } → { data: { id, consentLink } } 201
- POST /api/v1/bank-connections/:id/renew → { data: { consentLink } }
- POST /api/v1/bank-connections/:id/sync → { data: { fetched, matched, mismatched, unmatched, skippedDuplicates } } or 429
- DELETE /api/v1/bank-connections/:id → { data: { id, status: "revoked" } }

DashboardSidebar component (apps/web/components/DashboardSidebar.tsx) accepts items: Array<{ key, href, iconName, label }>. The iconName is mapped to a lucide-react icon component at render time. Banknote MUST already be supported by the sidebar — if not, the sidebar mapping must be extended in this plan as part of the layout task.
