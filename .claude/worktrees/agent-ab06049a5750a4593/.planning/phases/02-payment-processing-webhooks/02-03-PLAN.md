**GET `/` (PAY-01) -- List payments with status filter:**

Query parameter validation with `zValidator("query", ...)`:
- `status`: optional enum `["pending", "processing", "paid", "failed", "cancelled", "refunded"]`
- `leaseId`: optional string uuid
- `page`: optional coerce number, default 1
- `perPage`: optional coerce number, default 50, max 100

Implementation:
1. `const ownerId = getRequiredUserId(c);`
2. Build conditions array: always include `eq(leases.ownerId, ownerId)`. Add `eq(payments.status, status)` if status param provided. Add `eq(payments.leaseId, leaseId)` if leaseId param provided.
3. Query: `db.select().from(payments).innerJoin(leases, eq(payments.leaseId, leases.id)).where(and(...conditions)).orderBy(desc(payments.dueDate)).limit(perPage).offset((page - 1) * perPage)`
4. Return: `c.json({ data: result.map(r => r.payments), meta: { total: result.length, page, perPage } })`

Note: The join ensures ownership filter. Only payments belonging to the authenticated landlord's leases are returned.

5. Calculate amount: `data.amount || Number(lease.monthlyRent) + Number(lease.monthlyCharges)`
6. Generate idempotency key: `const idempotencyKey = crypto.randomUUID();`
7. Call `gcCreatePayment({ mandateId: lease.gocardlessMandateId, amount, description: data.description || "Rent payment", chargeDate: data.chargeDate, metadata: { lease_id: data.leaseId }, idempotencyKey })`
8. Create payment record: `db.insert(payments).values({ id: crypto.randomUUID(), leaseId: data.leaseId, amount: String(amount), dueDate: gcResult.chargeDate, status: "processing", method: "gocardless", gocardlessPaymentId: gcResult.paymentId, structuredCommunication: lease.structuredCommunication, rentAmount: lease.monthlyRent, chargesAmount: lease.monthlyCharges, createdAt: new Date(), updatedAt: new Date() })`
9. Return: `c.json({ data: { id, gocardlessPaymentId: gcResult.paymentId, status: "processing", chargeDate: gcResult.chargeDate, amount } }, 201)`

**POST `/:id/retry` (PAY-05) -- Retry failed payment:**
1. `const ownerId = getRequiredUserId(c);`
2. Find payment with ownership check (join leases)
3. If not found: 404. If status is not `"failed"`: return `c.json({ error: "Only failed payments can be retried" }, 400)`
4. If no `gocardlessPaymentId`: return `c.json({ error: "Only GoCardless payments can be retried" }, 400)`
5. Call `gcRetryPayment(payment.gocardlessPaymentId)`
6. Transition: `transitionPayment(payment.id, "processing")`
7. Return: `c.json({ data: { id: payment.id, status: "processing" } })`

**POST `/:id/cancel` (PAY-06) -- Cancel pending payment:**
1. `const ownerId = getRequiredUserId(c);`
2. Find payment with ownership check (join leases)
3. If not found: 404. If status is not `"pending"` and not `"processing"`: return `c.json({ error: "Only pending or processing payments can be cancelled" }, 400)`
4. If `gocardlessPaymentId`: call `gcCancelPayment(payment.gocardlessPaymentId)`
5. Transition: `transitionPayment(payment.id, "cancelled")`
6. Return: `c.json({ data: { id: payment.id, status: "cancelled" } })`
