**Replace `processEvent`** with idempotent wrapper (per D-10):
1. Check if `event.id` already exists in `webhookEvents` table using `db.query.webhookEvents.findFirst({ where: eq(webhookEvents.eventId, event.id) })`
2. If exists, log `[Webhook] Skipping duplicate event ${event.id}` and return
3. If new, insert into `webhookEvents` with: `id: crypto.randomUUID()`, `eventId: event.id`, `resourceType: event.resource_type`, `action: event.action`, `resourceId: event.links[event.resource_type] || event.links.payment || event.links.mandate || ""`, `payload: event`, `status: "processing"`, `receivedAt: new Date()`
4. Wrap event processing in try/catch:
   - On success: update webhookEvent status to `"processed"`, set `processedAt: new Date()`
   - On error: update webhookEvent status to `"failed"`, set `errorMessage: String(err)`, then re-throw

**Replace `handlePaymentEvent`** with DB persistence:
1. Get `gcPaymentId` from `event.links.payment`
2. Look up internal status via `GC_PAYMENT_STATUS_MAP[event.action]`. If no mapping, log and return (skip informational events like `paid_out` if already handled)
3. Find payment by `gocardlessPaymentId`: `db.query.payments.findFirst({ where: eq(payments.gocardlessPaymentId, gcPaymentId) })`
4. If payment found: call `transitionPayment(payment.id, internalStatus, { paidDate: internalStatus === "paid" ? new Date().toISOString().split("T")[0] : undefined })`
5. If payment NOT found (per D-12: auto-create):
   a. Look up mandate ID from event links or by calling GoCardless API if needed
   b. Find lease by `gocardlessMandateId`: `db.query.leases.findFirst({ where: eq(leases.gocardlessMandateId, mandateIdFromLinks) })`
   c. If lease found: insert new payment with `id: crypto.randomUUID()`, `leaseId: lease.id`, `status: internalStatus`, `amount: "0.00"` (unknown amount), `dueDate: new Date().toISOString().split("T")[0]`, `method: "gocardless"`, `gocardlessPaymentId: gcPaymentId`, `notes: "Auto-created from webhook - amount unknown, needs review"`, `createdAt: new Date()`, `updatedAt: new Date()`
   d. If lease NOT found: log `[Webhook] Cannot resolve payment ${gcPaymentId} - no lease found for mandate` (event is still recorded in webhook_events for audit)

**Replace `handleMandateEvent`** with DB persistence:
1. Get `mandateId` from `event.links.mandate`
2. Look up internal status via `GC_MANDATE_STATUS_MAP[event.action]`. If no mapping, log and return
3. If mandate status is in `MANDATE_TERMINAL_STATUSES` (cancelled/failed/expired):
   a. Call `cascadeMandateCancellation(mandateId)` per D-13
   b. **Flag affected leases with a visible note per D-13** before clearing the mandate ID. For each affected lease, set the `notes` field to indicate the mandate event:
      ```typescript
      // First, get affected leases to flag them with notes
      const affectedLeases = await db.select({ id: leases.id, notes: leases.notes }).from(leases).where(eq(leases.gocardlessMandateId, mandateId));
      for (const lease of affectedLeases) {
        const flagNote = `Mandate ${mandateId} ${event.action} on ${new Date().toISOString().split("T")[0]} -- SEPA collection stopped, action required.`;
        const updatedNotes = lease.notes ? `${lease.notes}\n${flagNote}` : flagNote;
        await db.update(leases).set({ notes: updatedNotes, gocardlessMandateId: null, updatedAt: new Date() }).where(eq(leases.id, lease.id));
      }
      ```
      This ensures the landlord sees a visible indicator on the lease that the mandate was cancelled/failed and collection has stopped.
   c. Update affected tenants: `db.update(tenants).set({ gocardlessMandateId: null, updatedAt: new Date() }).where(eq(tenants.gocardlessMandateId, mandateId))`
   d. Log `[Webhook] Mandate ${mandateId} ${event.action}: flagged ${affectedLeases.length} lease(s) with notes, cleared mandate, cancelled pending payments`
4. If mandate becomes active (`GC_MANDATE_STATUS_MAP[event.action] === "active"`):
   a. Log `[Webhook] Mandate ${mandateId} is now active`
   b. No DB update needed (mandate ID is already stored from setup)
